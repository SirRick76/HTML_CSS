Formatar fotografias com CSS

Molduras, formas, filtros, sombras e efeitos: um exemplo por secção, com o código ao lado

1Moldura simples

A propriedade border desenha uma moldura à volta da imagem.

.moldura-simples {
  border: 8px solid #26221e;
}

<!-- HTML -->
<img class="moldura-simples"
     src="foto.jpg" alt="…">

2Cantos arredondados e círculo

border-radius arredonda os cantos; com 50% numa imagem quadrada obtém-se um círculo. object-fit: cover evita que a foto fique deformada.

.arredondada { border-radius: 20px; }

.circulo {
  width: 200px;
  height: 200px;
  object-fit: cover;   /* corta sem deformar */
  border-radius: 50%;
  border: 6px solid white;
  /* segundo anel: sombra sem desfoque */
  box-shadow: 0 0 0 4px #c2410c;
}

3Polaroid

<figure> + <figcaption>, margem inferior maior, uma fonte manuscrita e uma pequena rotação. Passe o rato!

.polaroid {
  padding: 12px 12px 0;
  background: white;
  box-shadow: 0 10px 25px rgb(0 0 0 / .2);
  transform: rotate(-4deg);
  transition: transform .3s ease;
}
.polaroid:hover {
  transform: rotate(0) scale(1.05);
}
.polaroid figcaption {
  font-family: "Caveat", cursive;
  font-size: 1.6rem;
  text-align: center;
}

4Moldura de quadro com passe-partout

O padding faz o passe-partout, a border com 4 cores diferentes simula luz e sombra na madeira e duas sombras dão profundidade.

.quadro {
  padding: 30px;                 /* passe-partout */
  background: #f7f3ea;
  border: 22px solid;
  /* topo, direita, baixo, esquerda */
  border-color: #6e4524 #4a2e15
                #3c2511 #5b3a1e;
  box-shadow:
    inset 0 0 8px rgb(0 0 0 / .35),
    0 15px 30px rgb(0 0 0 / .35);
}

5Moldura dourada

border-image permite usar um gradiente como borda — ideal para efeitos metálicos.

.dourada {
  padding: 10px;
  background: #1b1b1f;
  border: 18px solid;
  border-image: linear-gradient(135deg,
      #8a6d1d, #f6e27a, #b8902c,
      #fff3b0, #8a6d1d) 1;
  box-shadow: 0 15px 35px rgb(0 0 0 / .5);
}

6Bordas dupla, tracejada e outline

Estilos de borda: double, dashed, dotted… O outline com outline-offset cria uma moldura afastada.

.dupla {
  padding: 6px;
  border: 6px double #1e3a8a;
}
.tracejada {
  padding: 8px;
  border: 4px dashed #c2410c;
  border-radius: 14px;
}
.outline {
  outline: 3px solid #0f766e;
  outline-offset: 10px;
}

7Sombras

box-shadow: x y desfoque cor. Sem desfoque fica uma sombra «dura»; várias sombras coloridas criam um brilho neon.

.sombra-suave {
  border-radius: 12px;
  box-shadow: 0 10px 30px rgb(0 0 0 / .2);
}
.sombra-dura {
  box-shadow: 14px 14px 0 #26221e;
}
.neon {
  border-radius: 12px;
  box-shadow: 0 0 10px #22d3ee,
              0 0 30px #22d3ee,
              0 0 60px #a855f7;
}

8Foto colada com fita-cola

O pseudo-elemento ::before desenha a fita sem precisar de mais HTML. Precisa de um contentor, porque <img> não aceita ::before.

.fita {
  position: relative;
  padding: 10px;
  background: white;
  transform: rotate(2deg);
}
.fita::before {
  content: "";
  position: absolute;
  top: -14px;
  left: 50%;
  width: 110px;
  height: 32px;
  background: rgb(255 235 150 / .75);
  transform: translateX(-50%) rotate(-4deg);
}

9Filtros

A propriedade filter aplica efeitos como num editor de imagem — e podem combinar-se vários.

.f-cinza     { filter: grayscale(100%); }
.f-sepia     { filter: sepia(90%); }
.f-desfoque  { filter: blur(3px); }
.f-contraste { filter: contrast(160%) saturate(140%); }
.f-brilho    { filter: brightness(140%); }
.f-matiz     { filter: hue-rotate(180deg); }
.f-inverter  { filter: invert(100%); }
/* Combinar filtros: separar por espaços */
.f-vintage   { filter: sepia(50%) contrast(110%) brightness(95%) saturate(80%); }

10Efeitos ao passar o rato

Combinação de :hover com transition. No zoom, o contentor tem overflow: hidden para a foto não sair da caixa.

/* Zoom: a caixa fica igual, a foto cresce lá dentro */
.zoom           { overflow: hidden; border-radius: 12px; }
.zoom img       { transition: transform .5s ease; }
.zoom:hover img { transform: scale(1.15); }

/* Preto e branco → cor */
.cor-ao-passar       { filter: grayscale(100%); transition: filter .4s ease; }
.cor-ao-passar:hover { filter: grayscale(0); }

/* Levantar */
.levantar:hover { transform: translateY(-10px); box-shadow: 0 20px 30px rgb(0 0 0 / .25); }

/* Rodar */
.rodar:hover { transform: rotate(-5deg) scale(1.05); }

11Legenda sobreposta

Pai com position: relative, legenda com position: absolute, escondida fora da caixa e que sobe ao passar o rato.

.sobreposta {
  position: relative;
  overflow: hidden;
}
.sobreposta figcaption {
  position: absolute;
  inset: auto 0 0 0;    /* colada em baixo */
  color: white;
  background: linear-gradient(
      transparent, rgb(0 0 0 / .8));
  transform: translateY(100%);
  transition: transform .35s ease;
}
.sobreposta:hover figcaption {
  transform: translateY(0);
}

12Formas com clip-path

clip-path recorta a imagem com qualquer forma. Os pontos do polygon() são coordenadas X Y em percentagem. Gerador útil: bennettfeely.com/clippy.

.hexagono { clip-path: polygon(25% 0, 75% 0, 100% 50%, 75% 100%, 25% 100%, 0 50%); }
.losango  { clip-path: polygon(50% 0, 100% 50%, 50% 100%, 0 50%); }
.estrela  { clip-path: polygon(50% 0, 61% 35%, 98% 35%, 68% 57%, 79% 91%,
                              50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%); }
.diagonal { clip-path: polygon(0 0, 100% 0, 100% 80%, 0 100%); }
.elipse   { clip-path: ellipse(45% 35% at 50% 50%); }
/* Sem clip-path: 4 cantos diferentes no border-radius */
.gota     { border-radius: 50% 0 50% 50%; }

13object-fit: encaixar a foto numa caixa

A mesma foto panorâmica numa caixa quadrada de 200×200. cover é o mais usado em galerias e cartões.

.encaixe img { width: 200px; height: 200px; }

.of-fill    { object-fit: fill; }      /* valor por omissão: estica */
.of-cover   { object-fit: cover; }     /* preenche e corta o excesso */
.of-contain { object-fit: contain; }   /* mostra tudo, sobra espaço */
.of-posicao { object-fit: cover; object-position: right; }

14Vinheta e duotone

Uma sombra interior (inset) num ::after escurece os cantos. Com mix-blend-mode a foto mistura-se com cores, como num editor.

.vinheta { position: relative; overflow: hidden; }
.vinheta::after {
  content: "";
  position: absolute;
  inset: 0;
  box-shadow: inset 0 0 80px 20px rgb(0 0 0 / .8);
}

.duotone { position: relative; background: #1e3a8a; }
.duotone img {
  filter: grayscale(100%) contrast(120%);
  mix-blend-mode: screen;
}
.duotone::after {
  content: ""; position: absolute; inset: 0;
  background: #f97316;
  mix-blend-mode: multiply;
}

15Fotos empilhadas

Três fotos sobrepostas com position: absolute, rodadas com :nth-child. Ao passar o rato abrem-se em leque.

.pilha { position: relative; width: 320px; height: 260px; }
.pilha img {
  position: absolute;
  inset: 0;
  margin: auto;
  border: 10px solid white;
  transition: transform .4s ease;
}
.pilha img:nth-child(1) { transform: rotate(-8deg); }
.pilha img:nth-child(2) { transform: rotate(5deg); }

.pilha:hover img:nth-child(1) {
  transform: rotate(-15deg) translateX(-90px);
}
.pilha:hover img:nth-child(2) {
  transform: rotate(12deg) translateX(90px);
}

16Tira de filme

Os furos são desenhados só com repeating-linear-gradient no fundo do contentor — sem imagens extra.

.filme {
  display: flex;
  gap: 12px;
  padding: 28px 14px;
  background-color: #111;
  /* duas filas de furos: 14px de cor clara, 16px de intervalo */
  background-image:
    repeating-linear-gradient(90deg, #f4f1ec 0 14px, transparent 14px 30px),
    repeating-linear-gradient(90deg, #f4f1ec 0 14px, transparent 14px 30px);
  background-size: 100% 10px, 100% 10px;
  background-position: 0 9px, 0 calc(100% - 9px);
  background-repeat: no-repeat;
}
.filme img { width: 170px; height: 120px; object-fit: cover; filter: sepia(30%); }

17Galeria em grelha (CSS Grid)

Colunas automáticas com auto-fill + minmax(), e algumas fotos maiores com span. Redimensione a janela!

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(160px, 1fr));
  grid-auto-rows: 160px;
  gap: 10px;
}
.galeria img { width: 100%; height: 100%; object-fit: cover; border-radius: 10px; }

.galeria .grande { grid-column: span 2; grid-row: span 2; }
.galeria .alta   { grid-row: span 2; }
.galeria .larga  { grid-column: span 2; }

18Texto a contornar a foto

float põe a foto ao lado do texto e shape-outside faz o texto seguir a forma redonda.

A fotografia está alinhada à esquerda com float. Graças ao shape-outside: circle(50%), as linhas de texto não ficam alinhadas a direito: acompanham a curva da imagem, como numa revista. Esta técnica funciona com círculos, elipses, polígonos e até com a transparência de uma imagem PNG. Escreva mais texto aqui para ver o efeito com clareza, ou reduza a largura da janela do browser e repare como as linhas se adaptam à forma da fotografia.

.contornar img {
  float: left;
  width: 200px;
  height: 200px;
  object-fit: cover;
  margin: 0 1.5rem 1rem 0;
  border-radius: 50%;
  shape-outside: circle(50%);
}

19Proporção fixa (aspect-ratio)

Garante que todas as fotos têm a mesma proporção, seja qual for o tamanho original.

.proporcoes img {
  width: 100%;
  object-fit: cover;
}
.r-quadrado { aspect-ratio: 1 / 1; }
.r-video    { aspect-ratio: 16 / 9; }
.r-retrato  { aspect-ratio: 3 / 4; }
